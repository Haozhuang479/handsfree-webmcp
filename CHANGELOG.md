# Changelog

## 0.5.1 — 2026-09-02
- Index-finger air-tap replaces the fist for clicking; cursor particles removed; near-invisible dot grid away from the cursor.

## 0.5.0
- Full-screen dot field with teal scroll bands; bold cursor; lower-corner control regions so the arm can rest low; no spoken feedback by default.
- Voice: ASR corrections, number words, filler stripping, price phrases → filters; new intents forward / browse / cheaper / pricier / more / describe.

## 0.4.x
- Hover-to-scroll horizontal rails via `handsfree:cursor`; `data-hf-scroll="x"` pauses vertical zones.
- Shim aligned with the current WebMCP draft (`registerTool(tool, {signal})`, `getTools`, `executeTool`, `toolchange`).

## 0.3.x
- Side scroll zones + fist click; walkthrough tutorial that starts the camera only at its end; popup-safe navigation; `back` dismisses panels.

## 0.2.x
- Projected cursor, pinch click, swipes, particle overlay, NILE-style dock icons.

## 0.1.0
- Skill, injector, runtime (voice + swipe gestures), tool-authoring reference.
